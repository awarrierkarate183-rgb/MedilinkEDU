Chapters

Chapter Support

Resources and direct help for chapters that already exist. New schools should start on Start a Chapter. Inactive chapters that need new student leadership should use reactivation, not this form. Existing officers can ask for the starter kit, competition prep, or coaching on the path to Flagship-Eligible at any time.

Help

What existing chapters can request

Need Track 1, meeting agendas, or the sample local case challenge? Chapter Support can resend the starter kit and walk officers through the four-track syllabus. Dates and formats for competitions come from your state chapter board. This site is the structure, not a calendar. Ask your chapter leader, then use this form if you need coaching on top of that.

Kit

Charter template, first 3 meeting agendas and decks, Track 1 Module 1.1, and a sample local case challenge. Full lessons still wait behind roster approval. Login is not live yet.

Compete

Prep help for Nationals, Innovation Challenge, Policy Cup, Research Symposium, and, in an Apex year, the biennial summit. Nationals uses the Regional to State to National ladder. The other three annual events do not.

Lead

Officer roles, recruiting, and the path to Flagship-Eligible. Also: activity planning, curriculum delivery, member recruitment, community partnerships, and recognition on the MediLink site after leadership reviews real work.

Who this is for

Existing chapters. New schools should not use this form. They should start a chapter. Reactivation is a different email: Chapter Reactivation.

Request

Existing chapters can request help at any time

Ask for help with events or operations. New schools should not use this form. They should start a chapter. If the request button alerts you, the Google Form URL is not in data/forms.config.js yet. Email medi.link.edu@gmail.com until it is.
